# Restaurant & Cafe — Multi-location

Internal ASAA demonstration template for a restaurant & cafe website.

## Purpose

Demonstrate the multi-location experience, page structure and responsive presentation for this business type. All names, descriptions, contact details, locations, schedules, products and media are synthetic placeholders.

## Usage

Generate a project from this template in the ASAA Templates workspace. Review the generated source, replace sample content, verify responsive layouts and accessibility, and configure real business information before deployment.

## Safety

This package is a static demonstration only. Forms and calls to action do not submit data or create real bookings, orders, payments or customer records. Complete content, privacy, security, legal and operational reviews before production use.
