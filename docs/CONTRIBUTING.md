# Contribution Guide

Until application development begins, contributions should focus on clarifying the product model and taxonomy.

## Before adding a template
1. Confirm ownership and license.
2. Assign a stable ID, family, sector tags, and division.
3. Add documentation, required inputs, supported technologies, and dependencies.
4. Identify security, privacy, accessibility, and compliance considerations.
5. State maturity accurately; do not mark untested work stable.
6. Include a changelog and maintenance owner.

## Pull request expectations
Describe purpose, affected areas, validation performed, known gaps, license provenance, and any migration impact. Never include secrets or client-sensitive information.
