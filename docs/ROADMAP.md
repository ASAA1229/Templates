# Roadmap

## Phase 0 — Repository foundation
- [x] Establish repository identity and top-level taxonomy.
- [x] Define product boundaries, sectors, divisions, lifecycle, and governance placeholders.
- [ ] Review and approve product scope and access model.

## Phase 1 — Catalog foundation
- [ ] Define catalog metadata schema and validation.
- [ ] Define storage and asset package conventions.
- [ ] Define search, filters, tags, and lifecycle administration.
- [ ] Add sample metadata records clearly marked as examples.

## Phase 2 — Authoring and preview
- [ ] Import/create template packages.
- [ ] Preview and validate template packages.
- [ ] Manage versions, changelogs, and compatibility.

## Phase 3 — Customization and generation
- [ ] Brand/content/layout/feature customization profiles.
- [ ] Generation wizard and independent output.
- [ ] Export/download and optional repository creation.
- [ ] Safe update/migration workflow.

## Phase 4 — Expanded product areas
- [ ] Resume and document studio.
- [ ] UI kit and design-system library.
- [ ] Sector packs and division-specific starter collections.
- [ ] Automation and developer/DevOps blueprints.

## Phase 5 — Integrations and productization
- [ ] Optional JARVIS connector with scoped permissions and user approvals.
- [ ] Team collaboration and roles.
- [ ] Licensing, client handoff, and optional marketplace readiness.

Phases are proposed sequencing, not committed delivery dates. Keep the product free-first and deliver incrementally.
